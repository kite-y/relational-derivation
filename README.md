## 先看主干，再看这里

主干给了方法：元素 = 含义 + 属性，两条线各自配对，聚散成网，每步可回溯。
**这个分支做的事：把塔罗填进那七步里。**

| 主干七步 | 塔罗这边填的是什么 |
|---|---|
| ① 切分 | 一张牌里的每个**象征物**算一个元素 |
| ② 含义 | 象征物的共识含义（牌面、颜色、物件都一样要走这一步） |
| ③ 属性 | 阴 / 阳 / 中；**只有颜色**额外带强度（极 / 衰） |
| ④ 判定表 | 6 行：阴-阳=对碰；阴-阴 / 阳-阳 / 中-中=重叠；中-阴 / 中-阳=交汇 |
| ⑤ 集合 | 同一张牌的象征物算一个集合体；一张牌就是一个集合体 |
| ⑥ 聚散 | 聚：三张牌的本有状态一对一配对；散：一个状态渗进另一张 |
| ⑦ 输出 | 三级标题 + 互动表 + 结构段 + 总况 |

## 闭环怎么验

```
选一张牌 → 拆象征物 → 每个给含义与属性
        → 两两判定，全部列出状态
        → 需要时聚（≥3 张，一对一配对）或散（单向渗入）
        → 输出里每一句都能指回某个象征物
```

**跑得通、指得回，就算接上了。**
