# 象征物体系 · Symbolism System

> 把「凭感觉的解读」拆成**可推导、可复现、可检查**的规则。
>
> 仓库只放**底层方法论**；具体领域（塔罗等）是它的**分支**，各自独立。

---

## 方法在做什么

模糊的东西进不来，得先切成**元素**。

每个元素只带两样东西：

| | 是什么 | 例 |
|---|---|---|
| **本有含义** | 它是什么 | 「白 = 纯粹」 |
| **本有属性** | 它是什么性质 | 「白 = 阳」 |

然后两两放一起，各走各的线：

```
本有含义 × 本有含义 → 后有含义      ← 说了什么
本有属性 × 本有属性 → 即时状态       ← 正在发生什么
本有属性 × 本有属性 → 本有状态       ← 它本来是什么状态
```

**含义和属性分开走，谁也不替谁下结论。**

---

## 再往上：集合体与聚散

多个元素合在一起，叫**模糊团（集合体）**。

| 层 | 里面发生什么 |
|---|---|
| **双集合体** | 两个元素 + 两个属性 → **即时状态**（会引发动作、修改） |
| **单集合体** | 两个元素 + 两个属性 → **本有状态** |
| **聚** | **至少 3 个**单集合体，彼此**本有状态相同** → 连成一张网 → **隐形集合**（方向自定义） |
| **散** | 一个单集合体的本有状态作为**因素**，散入另一个（或多个）→ 得到**后有含义** |

> **聚是一张网（横向连接），散是一条边（有方向）。**

---

## 四个词，别混

| 词 | 一句话 |
|---|---|
| **本有** | 元素自己带的（本有含义 / 本有属性） |
| **后有** | 两个本有含义交互之后才有的 |
| **即时状态** | 两个本有属性交互后得到，会引发动作 |
| **本有状态** | 也由属性交互得到，但用于判断“能不能聚 / 能不能散” |

## 边界与口吻

1. **它叫「镜」** —— 照见，不是预言。
2. **含义、属性都是「约定」**，写下来是因为：规则一致，推导就可复现。
3. **留白是特意的** —— 「交汇」不是没法判断，是主动留出来的空间。
4. **规律不等于预测。**
