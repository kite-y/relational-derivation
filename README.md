# 关系推导法

**中文** · [English](README.en.md)

> 一套把模糊的东西拆成**关系**、并且每一步都能追到来源的**定性方法**。
> 仓库里既有方法本身，也有一个能跑的引擎和示例。

---

## 这是什么

**不靠灵感，也不靠数字**，靠两条线：

- 每个东西拆成 **含义**（它像什么）和 **属性**（它属于哪一边）
- 含义配含义，出一条**新的说法**
- 属性配属性，出一个**关系状态**（对碰 / 重叠 / 交汇）

**唯一的硬要求：每一步都可回溯。**
结论能指回元素，元素能指回材料——除此之外不设别的门槛。

| 它能做什么 | 它不做什么 |
|---|---|
| 把零散材料（牌面、梦、访谈、界面元素、团队行为）整理成**看得见的结构** | **不量化**（含义不能测量，一比大小就失真） |
| 两个元素之间推一个**状态**，不靠发挥 | **不预测**（只把已有的关系摆出来） |
| 三个以上状态对得上就**合起来看**（聚）；整体状态**渗到别处**就长出新的说法（散） | **不下结论**（拿不准的地方留白） |
| 每个结论都能**指回具体元素**：可复现、可回溯、可反驳 | |

## 方法在做什么

任何可观察的东西，先切成**元素**，每个元素只带两样：

| | 问什么 | 例 |
|---|---|---|
| **含义** | 它像什么 | 「白」= 纯粹、干净 |
| **属性** | 它属于哪一边 | 「白」= 阳（外放、主动） |

**这两半从此各走各的，谁也不替谁下结论。**

---

## 一、关系只有四种

> **关系 = 两个东西在某个可比较的维度上相遇时，产生的结果。**

可比较的维度只有两个：**含义** 和 **属性**。由此只有四种关系：

| 类型 | 谁跟谁 | 方向 | 产出 |
|---|---|---|---|
| **判定关系** | 2 个元素（属性） | 对称 | 一个**状态** |
| **合成关系** | 2 个元素（含义） | 对称 | 一条**后有含义** |
| **连结关系（聚）** | 3 个以上集合体 | 无向（成网） | 一个**隐形集合** |
| **渗透关系（散）** | 1 个 → 多个集合体 | 单向 | 一条**后有含义** |

**为什么正好四种**：只有两种被作用的东西（含义 / 属性），只有两种规模（两个 / 多个）。2 × 2 = 4。

> **属性相遇出状态，含义相遇出说法；多个相连成网，一个外渗长出新说法。**

---

## 二、一个领域怎么闭环

领域要按顺序交出七样东西，**并且最后能回到原材料**：

```
① 切分     什么算一个元素
② 含义     每个元素像什么
③ 属性     每个元素属于哪一边（阴 / 阳 / 中）
④ 判定表   两两属性 → 状态（一般用同一张 6 行表）
⑤ 集合     哪些元素组成一个集合体
⑥ 聚散     哪些位置允许聚、哪些允许散
⑦ 输出     怎么把结果写成话
```

**闭环的四条检查**

| 检查 | 意思 |
|---|---|
| **能回去** | 每句结论都能指回 ① 里的某个元素 |
| **不漏** | 所有元素都被 ②③ 赋过值 |
| **不空** | 判定表里没有“说不清”的格子 |
| **不越界** | 输出不引入 ⑦ 之外的新东西 |

**换一个领域，就是换 ①②⑤⑥⑦；④ 基本不动。**

---

## 三、四个词，别混

| 词 | 一句话 |
|---|---|
| **本有** | 元素自己带的（含义 / 属性） |
| **后有** | 两个含义交互之后才有的 |
| **即时状态** | 双集合体里，两个属性自然产生的状态 |
| **本有状态** | 集合体内部，由特定双元素组合产生的状态 |

---

## 四、为什么不做量化

**含义不能测量。**

一量化就要比大小，而「纯粹」和「温暖」之间没有大小。
所以状态只有三种 + 一个「无状态」；强度只作用在**含义**上（过度 / 不足），不进状态。

**它的严谨不来自数字，来自三条：可复现、可回溯、可反驳。**

> **推演 ≠ 预测**：推演只把已有的关系摆出来，不负责说「将来会怎样」。
