# 引擎分层说明

> 引擎只认三个概念：**含义、属性、状态**。
> 它不认识颜色、不认识牌、不认识任何具体领域。

---

## 一、两层，各管什么

| 层 | 里面有什么 | 谁能改 |
|---|---|---|
| **引擎层**（`engine/engine.py`） | 元素、属性、状态、集合体、聚、散 | 改架构才动 |
| **领域层**（各分支自己写） | 含义怎么给、属性表、元素的定义 | 换领域只换这里 |

**判据**：一句话里出现具体领域词（颜色、牌名、方位），就属于领域层。

---

## 二、引擎里有什么

| 东西 | 作用 |
|---|---|
| `Element` | 本有含义 + 本有属性 |
| `post_meaning()` | 本有含义 × 本有含义 → **后有含义** |
| `judge()` | 本有属性 × 本有属性 → **状态** |
| `Collection` | 单集合体（多元素形成的一个整体） |
| `DualCollection` | 双集合体 → **即时状态** |
| `merge()` | **聚**：≥3 个集合体，本有状态重叠 → 隐形集合（方向自定义） |
| `seep()` | **散**：状态散入另外集合体 → 产生**后有含义** |

---

## 三、状态表只有一张（6 行）

**默认档位是阴 / 阳 / 中，但不是唯一选择。**

任何领域都可以换一套**质化档位**（冷 / 温 / 热、向内 / 中立 / 向外……），
**但换档位必须同时换状态表** —— 拿「阴/阳/中」的表去查「冷/温/热」，出来的状态是错的。

代码里就是 `Profile(name, tiers, table)`，`judge(a, b, profile=P)` 走自己的表。

| 属性1 | 属性2 | 状态 |
|---|---|---|
| 阴 | 阳 | 对碰 |
| 阴 | 阴 | 重叠 |
| 阳 | 阳 | 重叠 |
| 中 | 阴 | 交汇 |
| 中 | 阳 | 交汇 |
| 中 | 中 | 重叠 |

引擎里就是 `BASIC_TABLE`，**反着查同一张表**（对碰、重叠、交汇都是对称的）。

> 早先设计里的「极阳 / 衰阳 / 强对碰」属于旧版做法，**已不用**。

---

## 四、换一个领域，要做什么

| 换什么 | 在哪 |
|---|---|
| 元素怎么切、叫什么 | 领域层 |
| 每个元素的**本有含义** | 领域层 |
| 每个元素的**本有属性**（阴/阳/中） | 领域层 |
| 后有含义怎么写 | 领域层（`post_meaning` 的 rule） |
| 状态表 | 一般不用换，需要时也能整张替换 |

**引擎一行不改。**

## 五、现在还缺什么（如实标注）

| 项 | 状态 |
|---|---|
| 元素 / 状态 / 聚 / 散 | ✅ 已有 |
| 领域词零残留 | ✅ 引擎里搜不到任何具体领域名 |
| 旧版七档、深度调制 | ❌ 已删，不再支持 |
| 具体领域的专用逻辑 | 不在这个仓库 |

---

## 六、为什么不做程度量化

属性的变化只为**含义**服务。

一旦量化，就会开始比大小，而“意义”不是可以比大小的东西。
所以状态只有三种 + 一个“无状态”，没有强度、没有分数。

---

## 七、颜色与强度（唯一带强度的类别）

**只有「颜色」这一类元素会带强度**，其他类别一律没有。

### 强度是什么

| 强度 | 含义走向 |
|---|---|
| **极** | 该含义**过度** |
| **衰** | 该含义**不足** |
| 无 | 原样 |

### 引擎里的处理顺序（顺序不能乱）

```
① 先得到变化的强度
     深浅（单个颜色）：深 → 极　　浅 → 衰
     对立（两个颜色）：只有少数几对合法，成立才给强度
        ↓
② 用强度改写「含义」
     极 → 含义（过度）　　衰 → 含义（不足）
        ↓
③ 折回原有强度 —— 判定前必须做
     极阳 / 衰阳 → 阳　　极阴 / 衰阴 → 阴
        ↓
④ 再判定状态
     状态表永远是 6 行
```

**一句话：强度只走「含义」这条路，不进「状态」这条路。**

### 四条补充规则

1. **状态没有强度** —— 「强对碰 / 弱重叠」这种东西**不存在**。强度只属于元素。
2. **强度不改锚点** —— 核心语义不动，只是“过度/不足”的措辞。
3. **强度不叠加** —— 极再极还是极，不会再升级。
4. **强度要可回溯** —— 写了“过度”，就要能说出是哪次深浅 / 哪一对对立造成的。

### 引擎里的对应

```python
Element(meaning, attr, name, intensity="")   # intensity: "" / "极" / "衰"
fold(attr, intensity)        # ③ 折回三性（判定前调用）
with_intensity(meaning, i)   # ② 用强度改写含义
```
